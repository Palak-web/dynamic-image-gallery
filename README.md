# Dynamic Image Gallery

A modern, responsive image gallery with filtering and lightbox viewer built with vanilla JavaScript, HTML5, and CSS3.

## ✨ Features

- Category filtering (Nature, Architecture, Animals)
- Full-screen lightbox with higher resolution images
- Responsive design (desktop, tablet, mobile)
- Keyboard navigation (Arrow keys + Esc)
- Smooth animations & hover effects
- Lazy loading for performance
- Dark theme with glassmorphism

## 🚀 Quick Start

1. Download the files
2. Open `index.html` in your browser
3. That's it!

## 📁 Project Structure
── index.html # Main HTML
├── style.css # Styling
├── script.js # Gallery logic
└── README.md # This file

## 🛠️ Tech Stack

- HTML5, CSS3, JavaScript (ES6+)
- Font Awesome 6.4.0 (icons)
- Google Fonts (Inter)
- Unsplash (images)

## 🎨 Customization

Add images in `script.js`:

```javascript
{
    id: 21,
    src: 'image-url.jpg',
    category: 'nature',
    alt: 'Description'
}
```

Change colors in `style.css` variables:

```css
--primary: #3b82f6;
--bg-color: #0f172a;
```
